# Article Image Director

一个面向文章、教程和技术解释内容的 Codex Skill。它不会机械地“每段配一张图”，而是先找出真正需要视觉解释的内容，再生成一组风格一致、与正文紧密对应的编辑插画。

## 能解决什么问题

- 从文章全文或 URL 中提取值得可视化的关键节点。
- 在技术示意图、对比图、代码关系图和概念插画之间选择合适形式。
- 保留文章中的真实对象、代码标识符、调用关系和因果关系。
- 让多张图片共享统一的场景、色彩、材质和角色身份。
- 避免只生成“看起来很技术、实际上与文章无关”的泛化配图。

## 默认视觉方向

Skill 内置了一组视觉参考，默认采用温暖、日照充足的学习空间：木质桌面、纸张质感的讲解板、柔和的动漫编辑插画表现、克制的橄榄绿与蓝色，以及琥珀色高光。

默认主人公是一位穿深橄榄色宽松卫衣的年轻学习者。角色身份保持一致，但姿势、表情、视角和动作会根据每张图的解释目标变化。用户提供新角色后，新角色会替代默认主人公。

## 工作方式

1. 阅读文章，形成主题、受众、语气和叙事节奏摘要。
2. 选择最有解释价值的段落，而不是按篇幅平均切图。
3. 为每张图确定真实实体、必要关系、视觉形式和正文插入位置。
4. 建立统一的风格锁与角色锁。
5. 将技术内容放进温暖的插画场景中，逐张独立生成。
6. 检查文字、实体、关系、角色一致性和移动端可读性。

## 使用示例

```text
使用 article-image-director，为这篇文章生成 4 张配图：
https://example.com/article
```

也可以覆盖默认设置：

```text
为这篇教程生成 5 张 16:9 配图。使用我上传的人物作为主人公，
保留必要的代码标识符，但不要出现长段文字。
```

## 目录结构

```text
article-image-director/
├── SKILL.md
├── README.md
├── LICENSE
└── assets/
    ├── default-protagonist.png
    ├── style-reference-01.png
    ├── style-reference-02.png
    ├── style-reference-03.png
    └── style-reference-04.png
```

`SKILL.md` 是实际执行指令；`assets/` 中的图片用于默认风格和角色身份参考。

## 内容忠实度原则

每张图片都必须能够回答：

- 它对应文章中的哪一段？
- 它必须呈现哪些真实对象？
- 读者必须看懂什么关系？
- 如果换成另一篇文章，这张图是否仍然成立？

如果一张图可以不经修改地用于无关主题，它就过于泛化，需要重新设计。

## 注意事项

- 图像模型对长文本和复杂代码的拼写可靠性有限，应只保留必要的大号标签。
- 默认参考图决定的是视觉语言，而不是需要复制的固定构图。
- 角色是阅读视角和叙事线索，不能遮挡核心技术关系。
- 多张图片会分别生成，不会拼成一张联系表或拼贴图。
